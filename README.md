# Linux System Monitor

A small OOP-based system monitor written in Python.

This project reads Linux system information directly from files such as `/proc/stat` and `/proc/meminfo`.

## Current features

- Base `MetricCollector` class
- `CPUCollector`
- `MemoryCollector`

## Planned features

- Disk and process statistics
- Better data formatting
- GUI interface

## Goal

This is my OOP course project, focused on practicing inheritance, properties, methods, and building a small graphical application.
